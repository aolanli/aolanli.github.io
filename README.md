# Aolan Li — personal research website

This repository contains the source for
[aolanli.github.io](https://aolanli.github.io/), built with Jekyll and the
Minima theme.

## Main content

- `index.md`: homepage and selected work
- `research.md`: research areas, methods, talks, and open research
- `publications.md`: verified publication list
- `Aolan_Li_CV.tex`: editable website CV source
- `Aolan_Li_CV.pdf`: downloadable website CV
- `cv.html`: accessible CV viewer and download page

Shared professional facts and publication-status evidence are maintained in
the parent workspace's `profile/` directory. The website does not publish a
phone number or manuscripts in preparation.

## Local build

```sh
bundle install
bundle exec jekyll build
```
